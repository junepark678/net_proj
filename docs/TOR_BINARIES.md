## Tor configuration notes

Use `SocksPort auto`, `ControlPort auto`, `CookieAuthentication 1`, `ControlPortWriteToFile <private-path>`, `DataDirectory <private-path>`, `Log notice stdout`, and `ClientOnionAuthDir <private-path>`. Keep data and onion authorization files private. `ControlPortWriteToFile` writes a text file containing `PORT=<port>` and `COOKIE=<hex-encoded-control-cookie>` on separate lines; parse keys instead of assuming a fixed port. Control protocol uses cookie authentication from that file.

Android needs a foreground service while Tor remains available: declare a service type appropriate to the active work (`microphone` for an active call and `dataSync` only where policy/OS rules permit), and required foreground service permissions. Long-lived services are affected by Doze and vendor battery restrictions; explain the persistent notification and allow users to go offline. `android:process` changes app/service process ownership and lifecycle; keep Tor and its control client in a deliberately coordinated process. `extractNativeLibs` controls whether packaged native libraries are extracted; if false, do not assume a filesystem path exists. Prefer supported library loading/JNI if binary execution is unavailable.
